# Raizes-Consci-ncia-Negra-e-Cultura-Afro-Brasileira
Projeto educativo e interativo que valoriza a história, a cultura, a identidade e a ancestralidade negra. Apresenta conteúdos sobre resistência, manifestações afro-brasileiras, personalidades negras e igualdade racial, com recursos visuais, animações e elementos 3D. Desenvolvido com HTML, CSS, JavaScript e Three.js.
