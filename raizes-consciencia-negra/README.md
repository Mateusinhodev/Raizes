# Raízes — Cultura, História e Identidade

Projeto educativo sobre Consciência Negra desenvolvido com HTML5, CSS3, JavaScript e Three.js, seguindo a documentação do projeto.

## Como executar

1. Abra a pasta `raizes-consciencia-negra` no Visual Studio Code.
2. Abra o arquivo `index.html` com a extensão Live Server (recomendado) ou utilize um servidor local.
3. É necessária conexão com a internet para carregar Google Fonts, Three.js e fotografias hospedadas no Wikimedia Commons.

## Recursos implementados

- Menu responsivo e navegação por âncoras.
- Página inicial de destaque, com composição visual e elementos geométricos animados.
- Conteúdo histórico e linha do tempo interativa.
- Cards culturais com janelas de informação.
- Oito perfis de personalidades negras.
- Seção sobre resistência, igualdade, representatividade e reflexão.
- Galeria 3D com modelos geométricos, rotação por arraste, aproximação pela roda do mouse e botões de controle.
- Modo de alto contraste, animações de rolagem e layout adaptável.

## Imagens e créditos

As fotografias e imagens de referência são carregadas de páginas de arquivos do Wikimedia Commons. Consulte a página de cada arquivo para conferir autor e licença antes de redistribuir o projeto. Imagens históricas de Dandara e Zumbi não podem ser fotografias contemporâneas: as imagens exibidas são representações artísticas e estão identificadas como tais. O projeto não apresenta essas representações como retratos fotográficos autênticos.

## Observação sobre o 3D

Os três objetos da galeria são modelos estilizados gerados por código com Three.js. Eles são ilustrações educativas, não réplicas de objetos sagrados ou de uma tradição africana específica.
